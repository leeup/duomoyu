# Cloudflare Workers 一键部署

## 5 分钟流程

### ① 注册 Cloudflare（已有可跳过）

打开 https://dash.cloudflare.com/sign-up — 邮箱注册，免费。

### ② 安装 Wrangler CLI

```bash
npm install -g wrangler
```

如果没装 Node：先 `brew install node`。

### ③ 登录

```bash
wrangler login
```

会自动开浏览器让你授权。点 "Allow" 即可。

### ④ 进 worker 目录部署

```bash
cd ~/Documents/Claude/Projects/多摸鱼/worker
wrangler deploy
```

完成后命令行会输出：

```
✨ Successfully published your script to
   https://duomoyu-hotlist.<你的子域>.workers.dev
```

把这个 URL 复制下来。

### ⑤ 接入多摸鱼.html

打开 `多摸鱼.html` → 顶栏 **自定义** → 把 Worker URL 填进 **"自定义 Worker URL"** 输入框 → 保存。前端就会优先用你自己的 Worker。

### ⑥ 自检

直接在浏览器打开：

- `https://duomoyu-hotlist.xxxx.workers.dev/` — 看说明页
- `https://duomoyu-hotlist.xxxx.workers.dev/api/health` — 实际抓取一次每个平台，确认全部正常

- **10 万次/天** 请求
- **10ms CPU/次** 处理时间
- 无服务器维护

按多摸鱼一天打开 30 次、每次拉 10 个平台算，一个月也才 9000 次，离 10 万的天上限差得远。

## 修改

改 `worker.js` → `wrangler deploy` 重新发布即可。每次部署 1-2 秒。

## 删除

```bash
wrangler delete
```

## 常见问题

**Q: 部署失败 "Authentication error"**
A: 重新 `wrangler login`。或检查 https://dash.cloudflare.com 看账号是否正常。

**Q: 某个平台返回 502**
A: 上游接口可能临时改了，打开 `/api/health` 看哪个失败。改 `worker.js` 里对应平台的 `fetch()` 函数后重新部署。

**Q: 想加新平台？**
A: 在 `worker.js` 的 `PLATFORMS` 对象里加一项，写一个返回 `[{title, url, hot}]` 的 `fetch` 函数即可。
